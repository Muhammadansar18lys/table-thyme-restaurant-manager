# Table & Thyme - Restaurant Manager

A small restaurant management web app built with plain HTML, CSS, and JavaScript. Create table orders, monitor kitchen progress, and see which tables are available.

## Features

- Dashboard with sales, open orders, served orders, and occupied table counts
- Create orders with multiple menu items, quantities, guest counts, and kitchen notes
- Move tickets from **Preparing** to **Ready** to **Served**
- Search and filter the order board
- Click an available table to start an order for it
- Save orders in browser local storage, so they remain after refreshing
- Responsive layout for desktop and mobile
- No frameworks, packages, build step, or server required

## Run it

1. Download or clone the project.
2. Open `index.html` in a modern browser.
3. Use **New order** or tap an available table to create a ticket.

The app starts with sample orders to show the dashboard. To reset demo data, remove the `tableAndThyme.v1` key from your browser's local storage.

## Files

- `index.html` - page structure and order form
- `styles.css` - layout, colors, and responsive styles
- `app.js` - sample data, order actions, rendering, and local storage
